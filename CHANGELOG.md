## 0.2.617
- Your HUD layout no longer gets mixed up: hidden or closed elements (such as a closed chat) are no longer saved in the corner or the middle of the screen.
- A new install starts with a ready-made HUD layout instead of everything stacked in the default spots.

## 0.2.616
- Fixed a startup crash where a config file locked by antivirus or a sync tool stopped mods loading and left the main menu stuck.
- Added a Player tab to the F1 hub, with Stats, Appearance, Classes, Leaderboard and Achievements.
- The Mods settings are simpler: short plain descriptions, with advanced options tucked under Show Advanced.
- HUD panels can be dragged and resized without opening the layout editor, and the globe can be resized wide or tall.

## 0.2.588
- Crafting from nearby chests now also works for other Fires mods' stations, such as the Fires Loot Overhaul benches.

## 0.2.586
- Press Esc and drag any HUD element where you want it, and resize it from the corner handle; it is saved when you close the menu.
- The full layout editor (outlines, names, Reset, Cancel, Save) opens from the Edit layout button.
- Docking can be turned on or off while you move things (off by default, for free placement).
- Panels resize by width and height separately, and Reset also resets sizes.
- HUD elements from other Fires mods can be dragged and resized at any time.
- The quest tracker and territory box can be moved out of the minimap column; Reset puts them back.
- One inventory slot look everywhere: a dark square with a gold border.
- Pause menu buttons always work, even with the layout tools open.
- Esc no longer pops up hidden HUD pieces.
- Works with Jotunn mods that add their own build categories.
- The Alt+Shift context menu is off by default (turn it on in the settings for companion right-click commands).
- Core no longer changes other mods' logging unless you turn on Quiet other mods.
- Monster armour fits better, plus smoother combat aiming, climbing, companion fixes and better performance.
- Fixed the Achievements page emptying when you switched to a mod's tab.
- Fixed the old build menu showing up next to the new one.

## 0.2.219
- Smarter companions and better pathfinding.
- The Fires config window (F1) replaces ConfigurationManager and covers every installed mod, with sliders, drop-downs, a colour picker, keybind capture, a Files tab for editing config files, and a Conflicts view for clashing keybinds.
- Settings the server locks show greyed out; admins can hide settings from players.
- Your class's escape move can replace the dodge roll.
- Joining a server is faster, with no long freeze when joining with HD textures (which now load at half size by default).
- The server's item vault rolls back with the world after a crash, so items can't be duplicated or lost.
- The Chaos Hammer opens a full build menu with Categories, Biomes, Blueprints and Favorites tabs.
- Characters gather snow on their gear in the Deep North and shed it indoors.
- Companions follow, fight, block, use their real arrows, eat, drink meads, wear out and repair armour, sort chests and do their jobs properly in Valheim 1.0.
- Heavily built areas load faster, and buildings don't wear or collapse while the ground under them is still loading.
- Fires mods share one status box in the log, about once a minute.
- Server admins can edit recipes and creature drops, stars, health and damage in game with Fires All The Items.
- Items and effects from mods built for Valheim 1.0 no longer show up pink.
- Fixed custom dungeons losing their rooms on reload.
